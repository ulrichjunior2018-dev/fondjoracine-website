# Learn hero video

Place a compressed MP4 here as `learn-hero.mp4`.

Recommended:
- 1080p or 720p, H.264, muted ambient loop
- Keep under ~4 MB for mobile
- Square or vertical crop works best with the Learn product frame

Optional: set `NEXT_PUBLIC_LEARN_HERO_VIDEO` to a Cloudinary (or CDN) URL instead of this file.
